# Visual Recognition Competition in SAU

沈阳航空航天大学视觉识别比赛，个人学习与代码迭代记录。

使用 C++ 和 OpenCV 识别图片中的绿色弹丸，标出位置并统计数量。仓库按编号保存各阶段源码，当前最新版为 **#12，对应 v2.4 白平衡与饱和度修正**。

## 当前识别流程

1. 对输入图片做白平衡，计算绿色程度及其变化率。
2. 提取边界，检查更绿的一侧是否符合弹丸颜色。
3. 对边界点分组，通过 RANSAC 和最小二乘回归拟合圆。
4. 根据圆周与边界的贴合程度筛选候选，估计典型半径，再进行第二轮拟合。
5. 用剩余边界反测遮挡物，将被遮挡和出画的圆周从可见边界评价中排除。
6. 检查尺寸、圆内颜色、圆外绿色及圆心位置，绘制圆、编号和外接框，输出总数。

## 编译与运行

已有验证环境为 Ubuntu 24.04、OpenCV 4.6.0，使用 C++17。

安装好编译器、OpenCV 开发库和 pkg-config 后，在源码所在目录编译：

```bash
g++ -std=c++17 -O2 \
  "#12 边界拟合v6 白平衡与饱和度.cpp" \
  -o vision_demo \
  $(pkg-config --cflags --libs opencv4)
```

指定图片运行：

```bash
./vision_demo "/path/to/image.jpg"
```

需要显示过程图时：

```bash
./vision_demo "/path/to/image.jpg" --show
```

不传入图片路径时，默认读取当前目录的 `test_output.png`。

程序会在当前目录保存白平衡、绿色程度、边界和最终标注等过程图，终端输出各阶段数量及：

```text
GREEN BALLS: N
```

## 已有测试结果

根据已保存的测试记录，#12 在 5 张比赛题图上均输出 22，与人工确认数量一致。数量一致不代表每个检测位置都必然正确。

在由这 5 张图生成的 100 张合成变体中，已有记录为：

| 指标 | #12 结果 |
| --- | ---: |
| 检出率 | 97.1% |
| 误检总数 | 5 |
| 完全正确的图片数 | 76 / 100 |
| 平均绝对计数误差 | 0.69 |

合成变体包含亮度、色温、模糊、噪声、缩放和旋转等变化，属于基于原图的测试，不能代替新场景验证。测试脚本和图片尚未整理到本仓库。

## 已知问题

- 局部阴影和较暗区域仍可能漏检。
- 大量弹丸同时被严重遮挡时，典型半径估计可能失效。
- 参数主要根据现有 5 张题图调整，对新摆放、新背景和新杂物的适应能力仍需验证。
- 当前保留了全部历史源码，使用时请明确选择版本。
