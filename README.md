# Visual Recognition Competition in SAU

沈阳航空航天大学视觉识别比赛，个人学习与代码迭代记录。

使用 C++ 和 OpenCV 识别图片中的绿色弹丸，标出圆心、轮廓和外接框，并统计数量。仓库按编号保存独立源码，最新实验版为 **#22（v2.9.1）**。

## 识别流程

1. **前处理。** 从较亮、低饱和且未接近过曝的小块估计白平衡增益，再用有界 gamma 曲线修正 V。
2. **找边界。** 计算连续绿色程度及其梯度，同时生成 HSV 遮罩。梯度更绿的一侧通过颜色判断时，才保留该边界点。
3. **拟合圆。** 对边界点分组，用 RANSAC 生成圆并做最小二乘修正。第一轮估计典型半径，第二轮按尺寸继续拟合。用反向圆弧推断遮挡，按可见部分重新评分。
4. **检查圆内颜色。** 在圆心和四圈取 81 点，初筛和终筛都要求绿色得分达到 50%。最大连续绿区占比超过 30% 时，对相连、颜色接近的阴影点尝试补票。
5. **二次取色。** 至少有 3 颗可信球时，重新取球面样本。样本支持扩展 H 或 S 区间时，重建遮罩并再识别一轮，将新增球与首轮结果去重。
6. **检查圆外绿色。** 对合并后的候选统一计算无法归给邻球的圆外绿色比例。遮挡、普通、高贴合候选的上限分别为 20%、40%、50%。一次剔除超限圆，绘制结果并计数。

## 编译与运行

已在 Ubuntu 24.04、OpenCV 4.6.0、C++17 环境验证。各编号源码独立编译。

```bash
g++ -std=c++17 -O2 \
  "#22 边界拟合v16 圆外上限40.cpp" \
  -o vision_demo \
  $(pkg-config --cflags --libs opencv4)
./vision_demo "/path/to/image.jpg"
```

加 `--show` 显示过程图。省略图片路径时读取当前目录的 `test_output.png`。

| 输出文件 | 内容 |
| --- | --- |
| `0_white_samples.png` | 白平衡候选采样 |
| `0_white_balance.png`、`0_value_correction.png` | 白平衡和明度修正结果 |
| `2_ball_color.png`、`4_border_points.png` | 第一轮绿色遮罩和拟合边界 |
| `7_candidates.png`、`8_first_result.png` | 第一轮候选及通过圆内检查的结果 |
| `resample_*.png` | 二次取色触发后保存的第二轮过程图 |
| `9_outside_candidates.png` | 合并后的圆外检查，橙色标记超限候选 |

### 历史对照

#12 的历史记录中，五张题图均输出 22。基于这些题图生成的 100 张变体中，检出率为 97.1%，误检 5 个，76 张完全正确，平均绝对计数误差为 0.69。
