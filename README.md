沈阳航空航天大学视觉识别比赛，个人学习与代码迭代记录。

## 当前识别流程

1. 在 HSV 中筛选较亮、低饱和且未接近过曝的候选区域，不限制色相。
2. 对候选小块采样，在线性 RGB 中比较归一化通道比例，选出最集中的一组估计白平衡；样本不足或增益超限时跳过校正。
3. 计算绿色程度及其变化率，提取边界，检查更绿的一侧是否符合弹丸颜色。
4. 对边界点分组，通过 RANSAC 和最小二乘回归拟合圆。
5. 根据圆周与边界的贴合程度筛选候选，估计典型半径，再进行第二轮拟合。
6. 用剩余边界反测遮挡物，将被遮挡和出画的圆周从可见边界评价中排除。
7. 检查尺寸、圆内颜色、圆外绿色及圆心位置，绘制圆、编号和外接框，输出总数。

#14 仅替换白平衡并增加相关过程输出，后续颜色判断、边界提取、圆拟合和筛选逻辑沿用 #13。

## 编译与运行

已有验证环境为 Ubuntu 24.04、OpenCV 4.6.0，使用 C++17。当前输入按 sRGB 编码解释。

安装好编译器、OpenCV 开发库和 pkg-config 后，在源码所在目录编译：

```bash
g++ -std=c++17 -O2 \
  "#14 边界拟合v8 白色采样白平衡.cpp" \
  -o vision_demo \
  $(pkg-config --cflags --libs opencv4)
```

指定图片运行：

```bash
./vision_demo "/path/to/image.jpg"
```

需要显示过程图时：

```bash
./vision_demo "/path/to/image.jpg" --show
```

不传入图片路径时，默认读取当前目录的 `test_output.png`。

程序会在当前目录保存白色采样、白平衡、绿色程度、边界和最终标注等过程图。其中，`0_white_samples.png` 中红点表示选中的候选组，黄点表示其他候选块。

终端输出白平衡候选数量、样本数量、BGR 通道增益、是否应用校正，以及各识别阶段数量和最终结果：

```text
WHITE CANDIDATES: ...
WHITE SAMPLES: ...
WHITE GAIN BGR: ...
WHITE STATUS: applied / skipped
GREEN BALLS: N
```

过程图使用固定文件名，批量测试时应为每张图片设置独立运行目录。

每版 35 次测试包括原图，以及偏暖、偏冷、变暗、提亮、gamma 压暗和渐变阴影六类变体：

| 指标 | #13 | #14 |

白平衡另通过 9 项基础检查。在图5人工选取的 8 处白球区域中，平均通道相对差由 #13 的 16.0% 降至 #14 的 2.6%，原图为 1.9%。该指标反映这些区域的中性程度，不代表全图颜色准确率。

本轮白平衡的白色中性度与整体计数表现并未同步改善，因此 #14 作为实验版保留。计数一致也不代表每个检测位置都正确；合成变体基于原图生成，不能代替新场景验证。测试脚本、原始数据与过程图尚未整理到本仓库。
